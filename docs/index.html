03 TRY IT YOURSELF

想亲自试试？
三步就能开始。

提供已构建的 Chrome 扩展包。解压后加载，无需先安装 Node.js 或配置服务。建议先用“你好”“谢谢”测试动作。

下载 Chrome 扩展 ZIP ↓ 适用于 Chrome 116+ · ZIP 约 7 MB · 本地加载
  1. 01

    下载并解压

    点击下载，解压 ZIP。解压后的文件夹中应直接看到 manifest.json。

  2. 02

    在 Chrome 中加载

    打开 chrome://extensions，开启“开发者模式”，点击“加载已解压的扩展程序”，选中刚解压的文件夹。

  3. 03

    打开视频试一试

    进入视频网站，点击 SignBridge 图标。先手动输入“你好”或“谢谢”；需要语音识别时再按提示配置本地 Whisper。
