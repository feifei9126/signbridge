# 2026-10-19 功能精简（本地1.0.4）

这轮调整以现有素材和运行时为基础，减少普通使用入口。没有新增训练、视频、动作或语言批准；六批证据、权重和既有动作工具均保留。公开站点与旧安装包不会自动更新。

## 普通插件

弹窗保留六项操作：开始／停止字幕辅助、文字预览、视频声音开关、工作台、设置、帮助。固定显示中国手语，取消只有一个选项的手语类型选择器，以及此前实际回落为中文的字幕“自动检测”。字幕读取固定中文，音频识别语言仍可独立配置。

显示与声音配置统一进入原设置页。虚拟人大小、界面语言为普通设置；Whisper模型、识别语言、音频分片和云端参数收进“高级声音设置”。已有云端配置会自动展开高级区域，避免把正在使用的云端服务隐藏。保存设置保留旧配置和ASR值，向已打开的虚拟人发送大小更新，不向新网页注入角色。界面语言需重新打开相关页面后生效。

移除了未消费的外观、透明度、音量等历史默认值，既有存储字段不删除。Chrome扩展权限声明保持不变；声音下载／采集继续需要原有的明确用户操作。

## 工作台

- **动作演示**：默认自动匹配，显示实际播放来源、可用目录和未覆盖内容。保留播放、暂停、停止和速度。
- **意思分析（训练模型）**：进入现有本机角色模型客户端。它只分析有限中文角色，不加载动作、不自动连接或发出推理请求。仍需启动本机服务、填写当次口令。
- **研究工具与技术详情**：默认收起，集中放置动作制作（单帧姿势／多帧编排）、覆盖／补词、验收、强制动作来源、规则分析对照、三视角、原始／平滑、token、摘要、导出和训练对照图。

关闭研究区域会恢复自动匹配，避免隐藏着强制来源／规则分析状态。规则分析仍保持只分析、不播放；选择它会隐藏播放按钮及动作目录，并说明其与训练模型的区别。切换到意思分析会离开并停止动作页面，不继续后台播放。固定的“T08 · VQ-VAE”模型标签已取消，按实际来源提示。

制作、验收、覆盖工具仍需Chrome扩展环境。在普通本地HTTP演示页中显示扩展加载说明，不提供不可运行的工具链接。旧工具URL继续有效，现有动作草稿、批准状态和导入导出流程不变。

## 本机语义服务

完整构建只增加同一个轻量客户端页面，不包含模型、语料或新推理服务。完整插件打开服务自身的本机分析页，不为这条流程增加权限对话或放宽来源检查。独立轻量扩展保留原有直接连接方式；若使用该方式，服务仍需准确允许其扩展来源。

本地HTTP演示与语义服务可能使用不同端口。客户端会提示打开推理服务自身的分析页，跳转URL不携带口令或输入文本，不放开任意网页CORS。服务未启动时仍需先启动。单独轻量客户端版本为0.1.2，保留原六文件范围，不展示指向不存在工作台的导航。

从仓库根目录，可在新目录构建单独客户端并启动已有模型：

```sh
SIGNBRIDGE_PRIVATE_BUILD_DIR=/absolute/path/to/new-private-client npm --prefix signbridge run build:private
.venv-sign-data/bin/python signbridge/src/tools/sign-private-serve.py \
  --model local-data/csl-understanding-20261017-rLaeiN/learned-roles-v3 \
  --client /absolute/path/to/new-private-client --port 8770
```

扩展连接还需在上面命令中添加 `--allow-extension chrome-extension://实际32位扩展ID`。会话口令只从服务终端取得，不存入配置、URL或报告。客户端清空／离开页面会清除会话。

## 本地使用与验证

普通构建为 `npm --prefix signbridge run build`，在Chrome加载 `signbridge/dist/` 后，从弹窗打开工作台。完整T08／SMPL-X研究版继续按[显式资产构建说明](audit-remediation-20261019.md)创建新输出，不能因本轮界面精简把普通公开构建当作完整动作研究版。

新增 `feature-simplification.test.mjs` 与 `feature-browser-qa.mjs`，验证普通入口、设置保存、实际人物预览、工具可达、研究状态恢复、任务导航和手机布局。原覆盖／验收浏览器检查改为沿新工作台入口进入；旧动作研究检查先展开研究区域再操作原有控件。发布验收继续保存时间分隔报告。

## 验证结果

本轮构建、ESLint、Prettier和222项JavaScript测试通过；471项Python测试通过。六阶段既有浏览器回归、审计专项、新功能流程检查均通过。显式研究构建另外验证T08／SMPL-X播放、两句恢复配置、工具导航和手机布局。真实本机角色模型分别通过独立网页与完整插件工作台跳转后的13个用例；结果属于有限中文解析验证，不是中国手语准确率。

本地交付保存在 `local-data/feature-simplification-20261019-v1/`：`local-demo/`保留本轮显式选择的动作资产，`private-client-complete/`为独立轻量客户端。自动化测试不启动常驻推理服务；日常意思分析仍需按前文启动本机服务。结构化验证记录与截图保存在同一交付目录，人工语言质量标记和发布门禁仍未升级。
