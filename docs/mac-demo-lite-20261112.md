# SignBridge 轻量演示版（Mac）

适用 Apple 芯片 Mac，系统 macOS 13 及以上。只在当前 Apple 芯片 Mac 上验证过，Intel Mac 和 Windows 未验证。

## 安装步骤

1. 双击 `SignBridge-Demo-2.0.0.pkg`，按系统提示一路点“继续”，应用装到“应用程序”。
2. 打开 **SignBridge Demo**。应用没有 Apple 公证，首次打开如被拦截，请右键点应用选“打开”，或在“系统设置 → 隐私与安全性”里点“仍要打开”。
3. 点窗口顶部 **安装浏览器插件**，选择一个空文件夹（例如桌面新建“我的手语插件”），程序会校验并复制插件，然后打开该文件夹。
4. 点 **打开 Chrome 扩展页**，打开右上角“开发者模式”，选“加载已解压的扩展程序”，选上一步的文件夹。

Chrome 不允许静默安装未上架的本地插件，所以第 3、4 步需要手动完成。完全一键安装需要上架 Chrome Web Store 或使用企业策略。

## 轻量版包含什么

- 虚拟人物页面、141 条词库面板、动作播放。纯本机运行，只监听 127.0.0.1，不联网，不含 Python 和模型运行时。
- 141 条词库中约 73 条有动作（29 条原生候选加 44 条内置手工姿势），其余只显示词条，没有动作的词只给提示，不借用别的动作。
- 已删除带错误标记的实验动作，安装包约 19MB，应用约 55MB。

## 必须说明的限制

- 所有动作都是候选，`human_approved`、`training_ready` 仍为 false，不能说“输入文字就得到正确手语”。
- 轻量版不含模型推理，不是“输入任意中文生成手语”。107 类模型不在包内。
- 107 类模型验证集 1.0 只说明能区分同一录制的增强变体，不是真实泛化准确率，类别 103 到 106 各只有 1 条录制。
- 音节、镜像、手别、词界都没有经过手语专家认证。
- 127 条基础库里有 48 条既无素材也无来源，需要补录。
- 参考书《中国手语日常会话》第 118 页损坏，不能说已完整理解全书。
- 仅 ad-hoc 签名，没有 Apple 公证。

## 复现构建

```sh
/usr/bin/python3 src/tools/sign-mac-demo-lite.py --site /绝对路径/已核验的静态构建目录 --output /绝对路径/新的输出目录
```

脚本逐文件核对 `BUILD.json` 的 SHA-256，拒绝符号链接和越界路径，只复制清单内文件，编译 Swift，导出界面词条，做 ad-hoc 签名并复验。输出目录必须是新目录。
