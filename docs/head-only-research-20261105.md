# 冻结编码器的角色头对照 · 2026-11-05

本轮根据前次多任务退化执行逐句诊断和一次 GPU 对照；新结果保留为研究候选，不自动接入 Demo、不训练动作或更改待审素材。

## 错误诊断

固定前次 515 条 Gloss dev 的原始标签逐句比较：64 句编辑错误减少、71 句增加、380 句持平；替换 1,051→1,062，删除 449→420，插入 137→173，错误率 70.35%→71.12%。存在“你→我”、否定“不”漏掉等错误；编辑路径可能有并列解，仅是诊断线索，不证明根因。完整结果为交付目录 `error-analysis-v1/`。原 dev 已参与选模，不是独立测试。

## 冻结实验

使用 RTX 4090 D、CUDA 11.8，从既有 epoch-013 权重出发，仅训练角色头；编码器、词嵌入和 Gloss 解码器全部冻结，编码器保持 eval 模式。选角色 dev 整句匹配最优且同分取最早，最多 25 轮、patience 6，batch 64、AdamW 学习率 0.001、seed 20261105。训练完成 18 轮，选第 12 轮。没有使用正式 test、视频或动作，也没有按 90 条开发对照选模型。

旧词表不含“醋”，因此 60 条角色 train 和 45 条角色 dev 不能可靠表示，明确隔离而非用未知字训练。模型保留原词表；比较角色结果时分母为已知字的 8,843 条 train 和 1,548 条 dev。旧 881 条 dev 整句匹配 858→878；新 667 条已知字 dev 498→667。标签均为合成中文，不能当作手语准确率。

515 条 Gloss dev 的全部预测与初始模型完全一致，错误率仍为 70.35%。本机复核 70 个非角色头张量逐字节一致、角色头发生变化，并重新运行全部批量 dev 前向得到与 GPU 保存结果一致的逐项预测。2 条 Gloss dev 含未知字：批量指标使用 `<unk>`，实际研究推理对未知字会拒绝，因此不能把这两个批量预测当成用户可用输出。

## 范围保护与限制

原研究推理可能将“我没有工作”“我没有跑步”作为已确定结构接受。新研究规则对模型解析为相邻“没有＋谓词”的情况保守拒绝，要求人工复核：不是说“我没有跑步”不符合中文语法，也不等于模型已理解否定作用范围。规则只改研究推理，不改变 Demo 的动作逻辑。
