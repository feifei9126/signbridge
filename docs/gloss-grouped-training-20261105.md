# CE-CSL 分组从零训练结果 · 2026-11-05

本轮完成一项新随机初始化的 Gloss 研究训练、G 组选型和 H 组一次性留出评估。结果远未达到准确翻译：不升级旧模型，不接入 Demo，也不复用 H 调参。

## 训练与划分

- RTX 4090 D，PyTorch 2.2.2+cu118，CUDA 11.8；系统盘输出；训练进程退出后核对无残留训练/GPU进程。
- 训练4368条，来自源代码A-F、I-L；G组489条只用于checkpoint选择；H组101条在选定第17轮后评估一次。
- 新模型随机初始化，30轮上限、patience6、batch64、AdamW学习率0.0002、seed 20261105。实际23轮、1,587步，按G组Gloss错误率选checkpoint。
- 最终checkpoint SHA256：`0460de17411088b6e1ef7f466fadcbdc065caf5840046c996609b8174d9a9bde`。
- 正式test未读取。训练不读取G以外的selection之外数据，H未参与训练或选轮。

## 结果

| 划分        | 句数 | Gloss错误率 | 整句完全匹配 |
| ----------- | ---: | ----------: | -----------: |
| G选型组     |  489 |      76.96% |            0 |
| H一次性留出 |  101 |      94.31% |            0 |

G组由第1轮97.59%改善至第17轮76.96%，说明模型能拟合selection域；H结果显示跨该来源的泛化差。H身份代码并未证实唯一签者，故不能称独立签者测试。旧checkpoint已见过总体train池，不在H上比较旧模型，避免泄漏产生伪比较。

H共422个参考Gloss token，其中79个（18.72%）对应63种token未见于新train词表；55/101句含至少一个未见标签。模型平均输出2.86个Gloss token，参考平均4.18个。高OOV与短输出解释了部分低分，但不覆盖模型对于可见词的遗漏/替换问题，也不表示排除OOV后必然准确。详细逐句预测保存在留出报告。

## 采用结论

不采用该checkpoint作为原模型更新，也不输入Demo。留出H已按计划评估一次，不可再作参数调整、阈值筛选或数据修订的反馈集。将其判作本轮最终诊断后，后续若改变数据或词表，应另建新训练轮和新的、预先冻结的评估来源；现有H仅可列为历史已使用留出，不能再次声称未见评估。

来源代码不是已核实签者身份，精确去重不能排除近重复语义，稀疏Gloss监督、OOV及有限规模均是局限。样本仍是dataset-level Gloss，没有新增人工词界、词义或动作审核；实验不是中国手语准确率认证。`training_ready`、`model_training_ready`、`deployment_ready`、`human_approved` 仍 false。
