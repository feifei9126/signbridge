# 常见问题

## 虚拟人一直显示加载中

1. 在 `chrome://extensions` 重新加载 `dist/`。
2. 刷新视频页面。
3. 在开发者工具中确认出现 `[SB] Model loaded`、骨骼映射状态和 `[SB] Ready`。
4. 重新执行 `npm run build`，不要直接编辑 `dist/`。

## 有字幕但没有动作

- 确认视频已开启 CC 字幕。
- 在控制台查看是否出现 `[SB] Translation`。
- 未收录文本会被跳过，不会随机播放错误动作。
- 可在扩展弹窗中输入已知词，例如“你好”进行链路测试。

## 视频声音无法识别

- SignBridge 捕获当前标签页音频，不申请麦克风权限。
- Chrome 必须为 116 或更高版本。
- 先在“声音识别设置”中完成本地 Whisper 部署或云端 ASR 配置。
- 本地模型首次下载需要网络和足够存储空间。
- 云端模式需要检查端点、模型、API Key、计费和 CORS 支持。

## 本地 Whisper 下载失败

扩展会在 Hugging Face 官方源和镜像之间回退。请检查网络、浏览器存储空间，然后重新点击一键部署。首次部署成功后模型会被浏览器缓存。

## 手掌方向或肘部位置错误

不要直接在运行时反复修改角度。先在姿势编辑器中从正面和侧面确认，再通过录制器导出 REST 增量动作。模型更换时优先检查 `humanoid-rig.js` 的 profile 和坐标重定向。

## 浮窗如何操作

- 拖拽标题区域：移动整个浮窗。
- 在模型区域左右拖拽：旋转虚拟人。
- 在模型区域上下拖拽：上下平移虚拟人。
- 滚轮：缩放虚拟人。
- 右上角关闭按钮：关闭当前浮窗，可通过扩展弹窗重新启动。

## 支持哪些网站

扩展会在包含视频元素或常见播放器结构的网页中工作，并内置 Bilibili、YouTube、Netflix、Vimeo、Twitch、腾讯视频、爱奇艺、优酷等字幕选择器。网站 DOM 变化可能需要更新适配。

## 这是完整的自动手语翻译吗

不是。当前版本是可审计的词典和动作资产驱动系统，已知词会播放人工可检查的动作，未知词会跳过。完整 CSL 翻译还需要更大词典、句法重排、非手控特征和专业手语使用者验收。
