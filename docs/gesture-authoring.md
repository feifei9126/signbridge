# 添加和调试手语动作

动作贡献应先在工具页中完成和人工确认，再用于翻译。不要在 `iframe-bundle.js` 中反复猜模型骨骼轴。第二阶段已打通共享动作库，个人使用不必再复制数值到代码；向开源项目贡献内置词条仍需代码审查。

## 准备环境

还没确定先做哪些词时，先用控制面板的“词库覆盖分析”导入真实字幕，从高频缺词中加入本批清单（最多 8 个）。完整词组可手动加入，避免机械地按分词制作。清单跟踪保存/启用状态，不自动生成正确手语，步骤见[第六阶段补词闭环](phase6-acceptance.md)。

```bash
cd signbridge
npm install
npm run build
```

在 Chrome 中重新加载 `dist/` 后，关闭旧的工具标签页，通过扩展控制面板重新打开“姿势编辑器”或“录制工具”。工具必须来自同一扩展 ID、同一浏览器用户配置，才能共享动作库。

## 姿势编辑器

适合制作单帧姿势和校验单个骨骼：

1. 选择关节。
2. 调整 X、Y、Z 旋转。
3. 从正面和侧面检查手掌朝向、肘部位置和穿模。
4. 使用 A-Pose 归零确认所有值都是 REST 增量。
5. 在共享动作库填写动作名称、匹配文字和标签，点击“保存草稿”。
6. 点击“预览当前动作”，检查后选择“确认后用于翻译”。匹配文字留空时可只作为姿势素材保存。

编辑器只载入单帧动作；多帧文件请交给录制器，不会静默截取第一帧。

## 录制工具

适合制作包含多个关键帧的动作：

1. 调整姿势和“关键帧时长”，手动添加关键帧；连续采样可使用开始/停止录制。
2. 点击时间线中的帧，再调骨骼和时长，用“更新选中帧”保存该帧修改；只移动滑块不会回写旧帧。
3. 填写名称、匹配文字、标签并“保存草稿”。
4. 使用“预览当前动作”检查整个序列；编辑器和录制器都使用浮窗同款播放器。
5. 人工确认启用后，在控制面板输入匹配文字验证浮窗效果。修改后再保存会撤销旧确认，须再次预览、确认。
6. “下载统一 JSON”备份素材。导出不等于保存或启用；导入是新副本，也必须重新保存、确认。

工具页中左键拖拽旋转模型，滚轮缩放，右键拖拽平移视角。

录制器滑块是绝对本地弧度；导出的 `frames[].value` 是 REST 增量弧度。编辑器中的 `dg()` 预设仍在编写时接受度数，捕获后的文件不再转成度数或取整。旧文件迁移、单位与格式限制见[共享动作库操作说明](phase2-motion-library.md)。

## 保存后的可视化复查

控制面板 → **动作验收** 可以读取已保存的草稿和内置词条。先完整回放，再生成固定正面/右侧/左侧截图；每批最多 8 个动作，每个最多 12 个关键帧且包含首尾。人工检查后保存视觉基准，下次改动可以并排复查。

保存基准不修改关节参数，也不启用翻译；截图不能证明手语正确、所有过渡自然或没有穿模。修改后应重新完整回放，并按原有共享动作库流程预览、确认启用。详细步骤与基准备份限制见[第五阶段验收文档](phase5-motion-review.md)。

## 内置词条结构（面向代码贡献）

使用项目的 `deg()`、`frm()` 和动作构建函数，不手写不兼容对象：

```javascript
csl_example: {
  id: "csl_example",
  gloss: "示例",
  texts: ["示例", "例子"],
  tags: ["daily"],
  frames: [frm(gesture(A, "flat"), 0.7)],
  meta: {
    handshape: "flat",
    location: "chest",
    movement: "none",
  },
}
```

内置词汇 ID 使用 `csl_` 前缀，共享动作库自动生成 `custom_` ID。`texts` 应包含真实同义表达，但不要加入语义不一致的高频词来提高虚假命中率；自定义动作不能覆盖已存在的内置匹配文字。

## 手形原子

当前运行时提供：`fist`、`flat`、`point`、`thumbUp`、`peace`、`ok` 和 `relax`。手形会驱动完整指骨链；如果新手形无法由这些原子表达，应扩展 `handShape()` 并添加测试。

## 验收清单

- 正面与左右侧面都检查过手掌朝向。
- 肘部、手腕和手指没有穿过头部或躯干。
- 左右手符合动作定义，没有用镜像猜测代替验证。
- A-Pose 归零后模型回到稳定 REST 姿势。
- 连续播放时没有突然跳回或累计旋转。
- 新词条包含 gloss、别名、标签和手语参数元数据。
- `npm run verify` 完整通过。

建议在 Pull Request 中附上动作正面和侧面截图，并说明动作参考来源。请勿提交无授权教学视频或从中直接提取的受限素材。
