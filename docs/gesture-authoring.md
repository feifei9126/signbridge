# 添加和调试手语动作

动作贡献应先在工具页中完成和人工确认，再进入运行时词典。不要在 `iframe-bundle.js` 中反复猜模型骨骼轴。

## 准备环境

```bash
cd signbridge
npm install
npm run build
```

在 Chrome 中重新加载 `dist/` 后，通过扩展控制面板打开“姿势编辑器”或“录制工具”。

## 姿势编辑器

适合制作单帧姿势和校验单个骨骼：

1. 选择关节。
2. 调整 X、Y、Z 旋转。
3. 从正面和侧面检查手掌朝向、肘部位置和穿模。
4. 使用 A-Pose 归零确认所有值都是 REST 增量。
5. 导出动作数据并记录动作名称。

## 录制工具

适合制作包含多个关键帧的动作：

1. 开始录制。
2. 调整姿势后抓取关键帧。
3. 为每帧设置合理时长。
4. 预览完整动作，检查起止姿势和连续性。
5. 导出 `humanoid-local-v1` 动作数据。

工具页中左键拖拽旋转模型，滚轮缩放，右键拖拽平移视角。

## 词条结构

使用项目的 `deg()`、`frm()` 和动作构建函数，不手写不兼容对象：

```javascript
csl_example: {
  id: "csl_example",
  gloss: "示例",
  texts: ["示例", "例子"],
  tags: ["daily"],
  frames: [frm(gesture(A, "flat"), 0.7)],
  meta: {
    handshape: "flat",
    location: "chest",
    movement: "none",
  },
}
```

词汇 ID 使用 `csl_` 前缀。`texts` 应包含真实同义表达，但不要加入语义不一致的高频词来提高虚假命中率。

## 手形原子

当前运行时提供：`fist`、`flat`、`point`、`thumbUp`、`peace`、`ok` 和 `relax`。手形会驱动完整指骨链；如果新手形无法由这些原子表达，应扩展 `handShape()` 并添加测试。

## 验收清单

- 正面与左右侧面都检查过手掌朝向。
- 肘部、手腕和手指没有穿过头部或躯干。
- 左右手符合动作定义，没有用镜像猜测代替验证。
- A-Pose 归零后模型回到稳定 REST 姿势。
- 连续播放时没有突然跳回或累计旋转。
- 新词条包含 gloss、别名、标签和手语参数元数据。
- `npm run verify` 完整通过。

建议在 Pull Request 中附上动作正面和侧面截图，并说明动作参考来源。请勿提交无授权教学视频或从中直接提取的受限素材。
