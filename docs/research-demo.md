## 快速开始

使用 Python 3.10–3.12，解压完整工具包后，在解压目录打开终端：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python src/tools/sign-csl-learned.py --output runs/roles-v1 --examples 8000 --epochs 14 --seed 17
.venv/bin/python src/tools/sign-private-serve.py --model runs/roles-v1 --client client --port 8770
```

Windows可用 `py -3.12 -m venv .venv`，后续将 `.venv/bin/python` 替换为 `.venv\Scripts\python.exe`。无需 GPU 或 Node.js。训练输出必须使用新目录。

打开服务终端显示的本机页面，填写终端本次显示的会话口令。口令重启失效，不写文件、URL或浏览器存储。

可测试“我帮你”“你帮我”“我今天去学校”“今天我去学校”“我没有去”“你去吗”。“如果你来我就去”“我不想去”“我去火星”等超出当前范围的输入会拒绝。

也可在 Chrome 开发者模式加载工具包中的 `client` 目录。扩展来源跨域连接时，启动服务需附加 `--allow-extension chrome-extension://准确的32位扩展ID`，以 Chrome 实际显示为准；网页使用无需此参数。完整说明在包内 README。

## 能力与评测

模型使用 NumPy 平均结构感知机，更新字符上下文和BIO转移参数；分离施事、谓词、受事、目标、时间、否定、情态、疑问、体貌、请求、程度，共11类角色、32种谓词表面形式。

参考实验使用8000条助手合成中文样本，按“施事／谓词／对象”组合分组：6355训练、881验证、764测试；挑战文本从生成数据排除。验证和测试完整匹配，34条挑战通过，其中17条拒绝。**这是同开发者构造的简单、有限中文评测，不是中国手语准确率，也不能证明已理解开放域语言。** 没有基于这些分数授予手语动作或语言正确性批准。

解析成功仍显示中国手语对齐待复核；不会用词库或整句播放冒充新生成的手语。词级边界、镜像、侧别、空间指代、面部等非手部表达仍需语言与动作核验。
