# 2/100 全课程词义审计

本轮继续限定用户提供的 `/Users/mac/Desktop/手语/2/100/`，不扩大数据、不开新GPU训练、不改人物动作与现有模型。目标是先明确每课文字、中文义项、手语示范说明及它们之间的证据关系，纠正旧OCR或词句混标。

## 审计口径

- 62个物理文件按完整SHA-256去重为48份，约94.94分钟。全部原文件及重复别名保留。
- 逐源复用哈希绑定的5,697张采样画面，核验21,519行空间OCR。旧的每源1fps采样和3854条去重字幕，不等于精确逐帧词动作边界或完整语音转写。
- 新增对505个代表画面的标题/讲解区域放大重识别，共1,010个OCR裁图；保留新旧原文和置信度，不让第二次OCR自动充当词义真值。
- 每课审计记录含准确课题、内容类型、课程义项、标准中文书写、原始误读别名、时间范围、讲解原文、手型/位置/方向/动作序列说明、课内并列变体、非手部要求和留疑。
- 同一书写词的多个来源保留独立记录；不因中文标签相同就平均或替换手语动作，不把多种打法标为抖动。

本次“标准”首先指明确中文书写与课内义项。官方网页检索/原文抓取这轮未成功得到可用逐词标准资料，失败记录保留；不能把尝试检索写成完成标准核验。教程动作尚未逐词与正式国家通用手语词典进行独立对照，所以 `national_standard_match=not_checked`。不能将本次助手审计宣传为“全部视频的手语已获国家标准认证”或“模型已完全理解”。

## 必须分别处理的内容

1. **词、短语和整句**：我/我很好、早上/早上好、你们/你们好不能按标题自动拆出正确动作词界。讲解明确的组成部分作为教学子单元记录。
2. **人称与空间指代**：我/我们、你/你们、他/他们不能仅靠改文字复制同一姿态。原片未给出完整独立示范时保留缺项；大家不自动等同我们或他们。
3. **面部、头部与手部**：你好/你好吗、不想等可能有相同或相近手部而非手部不同。唱歌里的摇头也不能机械视为否定。讲解说话的嘴部运动不等于已标注的语言口型。
4. **并列变体**：上午、下午及其他词的多种课内打法独立保存，不做平均。
5. **语法教程**：宾语前置、否定/疑问后置、量词省略等保留为本课示例说明，不推广成所有中文的机械重排规则。
6. **指拼与数字**：汉语手指字母、数字构词分别成类；字母不是ASL、一个汉字出现不证明有对应独立手势，数字范围不拆成一万条词来虚增数量。
7. **测验与片头**：未公布答案的词汇/句子识读不猜答案；片头蒙太奇字幕不直接当作连续词动作监督。
8. **手语名字与类标记**：个性化取名示例、实体/操持/形状类标记属于概念与语境，不当作固定一对一中文词典。
9. **有意交叉与错误穿插**：拍臂、里外、接触词保留原片的必要交叉。二维重叠不等于三维穿模，数值平滑不等于表达正确。

## 证据与验证

新工具 `signbridge/src/tools/sign-csl-lexical-audit.py` 汇合四组逐课审计，要求48个来源完全覆盖、没有重复源。原视频重新核验SHA；讲解引文逐时间核对原OCR。无法精确绑定的引文作为告警保留，不作为自动训练依据。

误字修订按“源ID＋时间＋原始完整OCR行”应用；不对同样字形全局替换，不把“上午”改成“下午”等反义词。多行或语境修订不能悄悄回写单行。原OCR始终保留，修订另列。

每个旧标题窗口均给出对应义项、仅时间上下文或未映射留疑的处置；字表仅统计画面中文字符，不声称每字都有独立动作。最终CSV、JSONL、逐课文字记录、概念多源索引和可搜索HTML共同交付。

`human_approved/semantics_approved/boundaries_approved/training_ready/model_training_ready/csl_translation_verified=false`，`text_verified=""`。这不阻止自动研究审计，但禁止把助手判断伪造成人工批准；本轮不生成新模型权重。

## 复现

```sh
python3 src/tools/sign-csl-lexical-audit.py \
  --audit-root /absolute/frozen/audit-inputs \
  --annotations /absolute/group-1.json /absolute/group-2.json /absolute/group-3.json /absolute/group-4-main-v2.json \
  --output /absolute/NEW/assembled-audit
```

选择新的输出目录，原片与旧证据不会覆盖。标注输入、原视频、图片、重识别工具、输出和修订记录均保留SHA-256。可搜索页中的原片链接指向本机授权文件夹，交付包不重新上传原视频或扩大发布权限。

## 本轮结果与局限

48课汇总为573条课内义项记录，对应539个不同的“标签＋类型”组合，含449条词出现、32条短语、25条整句、35条指拼、9条数字、8条语法概念、10条手语名字概念、5条类标记概念。重复概念的不同来源保留；这些数量均不代表已训练或独立核准的动作数。

126条修订记录中124条可精确应用于单行OCR；另2条保留未决文字或源字幕/手型矛盾。477个旧标题窗口全部有处置：447条仅标签匹配、4条仅时间上下文、26条未映射。标签匹配不认证词级动作边界。

5条明确未决的源内记录为：第14课“不舒服”、第18课未公布答案的动物、第39课姓氏“周”、第47课“你”和“进步”。第47课的“你”仅指该次出现证据不足，其他课的同词审计独立保存，不能推断所有“你”都无法识别。

61张接触表与采样文字覆盖了48课，但本轮没有完成95分钟视频的连续逐帧专家判读，没有完整语音转写，也没有逐词国家通用手语词典对照。所有记录仍是助手来源审计，不能据此自动核准动作语义、镜像、左右手、边界或训练集划分。肢体交叉、抖动与面部的定量训练和重建不属于本轮结果。

输出采用新的版本化目录，v1及原标注保留，v2使用`group-4-main-v2.json`记录主审改动及其父文件SHA。交付包含可搜索页面、CSV、逐课可见文字、原图接触表、原始与修订文本和校验清单。原视频超链接依赖本机授权路径；压缩包不包含原视频。
