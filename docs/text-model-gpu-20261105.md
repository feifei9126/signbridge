这些不是中国手语翻译准确率。冻结对照中“我跑步”“你洗澡”“他开车”角色解析可用，但 Gloss 仍可能错误；例如“我跑步”生成候选还包含“一千”。“我帮你／你帮我”仍未解析通过；复合否定、情态和事件状态在最终结构门槛下仍被拒绝。

“我没有跑步”是语法正常的中文事件否定；冻结测试把它列为超出当时支持的语义契约，计为不当接受，**不是说这句话本身错误**。“我没有工作”则保留职业缺失／事件否定的语义歧义。原始 BIO 标签在 74 条目标中有 72 条与对照一致，不等于完成事件作用范围分析；最终可正确接受的目标只有 40 条。

Gloss dev 不退化及旧角色 dev 不退化为预先确定的晋升约束；Gloss 未通过，因此不替换旧模型。新增角色 dev 的 99% 和冻结超范围接受数不增加是运行后显式给出的补充诊断门槛，不伪称训练前登记的选模规则；其中后者也未通过。90 条冻结句只在选定 checkpoint 后评估一次，不用于逐轮选模。
