## 已发现并修正的问题

- 排队的 RAF 时间可能比动作首次编译后的 `performance.now()` 早。旧逻辑产生负时间和 `-1` 帧索引，导致渲染中断；现在时间增量下限为 0，包含红绿回归测试，并验证缓存重播。
- 头部校准曾使用面部子骨骼的方向，造成头部翻转。现在头颈保留直立 REST 朝向，实际骨架零姿态测试确认头颈不翻转，手臂继续按源方向校准。
- 播放后立即切换模式时，旧 iframe 的 CURRENT 消息曾恢复已经停止的界面。现在每个播放/停止请求带编号，过期事件被忽略；实际浏览器回归确认切模式后保持待机、暂停按钮禁用。
- 标点归一化曾同时删除未知符号，可能把“工作🚀忙吗”误匹配为完整参考句。现在保留未知符号，英文别名同时检查前后边界，相关用例通过。
