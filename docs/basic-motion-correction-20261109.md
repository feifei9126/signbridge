# 基础动作连续修正与未通过项（2026-11-09）

本轮纠正了先前“复核没有通过，任务却停止在报告阶段”的执行问题：沿用原授权实际修改姿态副本，再对修改后的同一版本重新检查。本次只处理基础词“我”“你”的两段连续姿态，共127帧，不代表127个基础词条已经修好，也不代表已训练新的语言或动作模型。

## 实际问题和修正

原生SMPL-X的手型、腕位与原视频不同。逐帧独立优化虽显著改善投影，却会选到不同的三维姿态分支，造成更大的手指跳变。因此保留逐帧失败试验，改为对连续有观测的片段进行联合优化，约束相邻帧的有效旋转，并保留源视频关键点误差。使用同来源关键帧作为手型先验，不能当成审批或真实三维标注。

每帧最多改变同侧手指、腕部和受限肘部；肘部相对原姿态不超过15度、腕部不超过80度、手指不超过155度。其他手、身体、位移、形状、面部和原生dtype保持不变。漏检帧保留原姿态和缺失标志，不插值、不补零。

`sign-basic-motion-correct.py` 增加了冻结输入身份链复验，包括源片、观测、源帧ID/PTS、annotation、原生参数/metadata/render的哈希。temporal候选必须重新满足原始投影、指尖、腕位和旋转门槛，不能因平滑而绕过原验收条件。

## 两轮验证和目前的真实结论

本轮完整保留了原片/原生/修正三栏视频和127帧对照，包含失败帧。第一项复验检查冻结身份、逐帧源投影与保护参数；第二项由独立审查程序检查姿态序列、缺失、版本和连续性。它们是技术复验，并非两次完整的中国手语动作正确性通过。三维手型/掌向、非手部语义、词界和网格碰撞的未证实项继续标为unknown；源侧2D前臂不交叉不能证明模型无穿插。
