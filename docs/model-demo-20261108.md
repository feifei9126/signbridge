# 本机模型 Demo 交付

新增 `/demo/model.html`，与原动作工作台同属 SignBridge Demo。真实语义模型通过同源本机 API 调用，
右侧复用既有 Three.js / Godette 人物播放器。用户已授权按“模型接入→有据动作→验收打包”完成，
本轮未启动 GPU、修改权重或推送 GitHub。

## 当前可以展示

- 学习模型输出人称实体，以及施事、事件、受事、时间、目标和否定/情态作用顺序。
- “我帮你／你帮我”和“我不想去／我想不去”的区别可在结构中直接看到。
- 真实拒绝保留；模型原始类型、BIO 和显式一致性标记在详情中可查看。
- 8 段已有 SMPL-X 拟合动作以**独立参考**方式播放。历史批准范围仅为 motion_quality_only，
  未新批准词义、词界、方向、手语语法、表情或模型到动作映射。

当前模型支持的基本句式与这 8 段已审阅参考没有完整的自动播放对应。页面因此显示缺口并停用自动匹配播放，
不能称为文字输入即正确手语动画。独立参考目录既不调用内置词库，也不冒充模型生成动作。
不会把施事和受事反转、否定漏掉或未知角色用后备动作拼掉。

## 实现

- `src/tools/sign-model-demo-serve.py`：只监听127.0.0.1，校验构建资源、历史动作审阅和本地模型，加载一次模型。
  `GET /v1/demo-session` 返回短期内存口令和参考目录，`POST /v1/understand` 调用真实模型。
- `src/tools/sign-model-demo-launch.py`：Mac双击启动入口；复用本机已经安装的固定运行时，不安装新依赖。
  已运行时用随机实例标识和语义检查点核对后复用，防止重复打开新模型进程。
- `src/demo/model-demo.js` / `model-demo-session.js`：输入代次和 AbortController 隔离过时请求，
  修改文字、选新参考或停止立即使旧结果失效并停止动作；iframe消息同时核对来源、origin和代次。
- `src/demo/model.html` / `model-demo.css`：桌面双栏、移动端单栏，页面字符串集中在 `src/i18n/locales.js`。
- `scripts/build.mjs`：三种既有profile均包含新页面；public build不带学习权重，实际服务使用独立本机包。

服务只开放BUILD清单中已核验的 demo/avatar 静态资源，不提供目录遍历、模型文件、训练语料、工具源码或配置下载。
Host/Origin/Sec-Fetch-Site、口令、JSON字段/长度/类型、限流和有界并发均校验；没有跨域授权。
GLB内嵌纹理需要同源生成的blob读取，CSP明确允许blob连接和图片，未开放外部HTTP目的地。
输入不写日志、不上传。部署在用户电脑且交付本地权重不能保证文件不被本机持有人复制；没有宣称防提取。

动作目录必须从实际实验index、历史审阅清单、质量列表和动作字节一致地取得。
目录依赖必须在BUILD清单内，index及clip均需要同一批准ID/状态，source/fitted摘要匹配；
实际pose用既有微单位规范化摘要与审阅记录绑定。技术stable不替代动作质量人工批准。

## 展示动作的技术验收

选入8段：哥哥、记者、中午、通知、市民、群众、我喜欢给小朋友讲故事、诗歌是一种文学形式。
沿用 `quaternion-temporal-v1` 显示层平滑，原始参数不改。
实际人物骨架计算：显示后手腕中点残差P95约0.50–1.83cm、手臂角度中点残差P95约1.12–1.38°。
8段的前臂内部中心线<8mm及手腕到躯干轴<4cm两个保守代理均未触发；
这不是皮肤网格碰撞检测，不保证零穿插、零抖动或语义正确。

真实浏览器验收覆盖：固定模型检查点、基本人物/否定/拒绝、全部8段完整播放、暂停/继续、快速替换、
修改即停、刷新、503恢复、移动布局、控制台与内嵌纹理。早期白模因CSP阻止blob，已修复并重测。
早期报告保留，最终报告以交付目录的最终QA记录为准。

## 使用与恢复

在“手语”目录中解压交付ZIP，双击 `启动模型Demo.command`。保持终端开启；Ctrl+C停止服务。
不要直接双击model.html的file://路径，它没有模型服务。无需GPU服务器。
模型、编码器和所需工具已随包保存；Python/PyTorch运行时复用同级
`SignBridge-中文迁移实验-20261106-98r014yn/runtime/bin/python`，本机已验证。
若目录移动到别处，应一并保留该同级运行时，或明确修改本地config运行时路径。
当前是Mac本机网页演示，不是包含Python模型的纯浏览器离线扩展或通用跨平台安装器。

有配对语义证据却没有动作证据时，结构可查看但不会自动播放。新增动作映射仍需来源与审阅对齐，
历史83段或后续待审集合的批准范围不扩大。所有训练/语义就绪字段继续false。
回退可使用原 `demo/index.html` 和此前交付包；本轮保留它们及全部旧模型和原始数据。
