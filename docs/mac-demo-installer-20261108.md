# SignBridge Mac 演示版安装包

适用 Apple 芯片 Mac（M1/M2/M3/M4等）。原生启动器目标为macOS13及以上；实际验收在当前Apple芯片Mac完成，未声称Intel/Windows或所有旧系统已验证。

## 安装和使用（1.0.10 自选插件目录）

推荐打开 `SignBridge-1.0.10-自选目录安装向导.zip`，解压后双击 **SignBridge 安装向导.app**：

1. 点击“选择…”，选择一个新建的空文件夹作为插件目录，例如桌面上的“我的手语插件”。界面会显示完整保存位置。
2. 点击“保存插件位置”。插件文件直接写到所选文件夹；这里打开就能看到 `manifest.json`，没有额外摘要子目录。
3. 点击“完成”关闭向导，再双击旁边的 `SignBridge-Demo.pkg`，按macOS系统向导完成安装，再从“应用程序”打开 **SignBridge Demo**。
4. 桌面程序显示同一个插件位置；点击 **打开插件文件夹** 直接打开它。另有 **更改插件位置** 和 **复制插件路径**。

默认插件位置为 `~/Desktop/SignBridge插件`。若选中的目录包含个人文件或不相符的旧插件，安装向导会提示换一个空文件夹，不覆盖其中内容。再次安装到同一份已核验插件目录会复用该目录。

备用 `SignBridge-Demo-1.0.10-Mac-AppleSilicon.pkg` 只安装桌面程序；直接使用备用包的用户，首次点“打开插件文件夹”时会要求选择保存位置，之后同样记住。

程序自动启动本机模型并在默认浏览器打开演示，不用安装Python、打开终端、填端口或准备GPU。展示完成后点击 **退出并停止服务**，或关闭启动器窗口。

首次启动会加载模型，等待启动器显示“模型已就绪”。所有运行时、权重和人物动作都随应用携带。默认使用8787端口；如端口被占用会自动选择新端口，启动器显示实际地址。不会结束占用端口的其他程序。

本机没有开发者签名身份，本次应用使用本地ad-hoc签名，安装包没有Apple开发者签名或公证。首次打开可能需要系统确认；本包不关闭或绕过macOS安全保护。

## 插件配合

桌面演示不需要安装插件。需要浏览器插件入口时，先运行桌面演示，再点 **打开插件文件夹**。按钮只使用安装时保存的位置，不再定位应用内部目录或隐藏路径。

在Chrome扩展管理页启用开发者模式，选择“加载已解压的扩展程序”，加载上面选定的文件夹。也可点 **复制插件路径**，在文件选择框按 **⌘⇧G** 后粘贴。浏览器扩展仍需用户显式加载，不能静默安装。

插件 → 模型演示Demo → 授权并连接。默认地址为 `http://127.0.0.1:8787`，端口冲突时改为启动器显示的地址。关闭桌面启动器会结束它拥有的模型服务，原公开动作工作台依然不依赖Python推理。

更改位置时选择新的空文件夹，程序复制并核验成功后才更新保存位置；取消或失败保留原设置，旧目录也保留。Chrome已加载旧路径时，需要重新加载新的文件夹。所选路径只记录于 `~/Library/Application Support/SignBridge Demo/installation.json`，不会把模型凭据写入设置。

## 展示范围

应用携带原公开快照100段动作：14条T08参考、3条T08候选、83条历史动作质量批准的拟合片段。模型页精选其中8条拟合动作作独立参考预览。100段不等于100个独立词条，也不表示全部已获得语言含义批准。

中文模型展示人物、施事/受事、否定与情态范围。例如“我帮你／你帮我”、“我不想去／我想不去”。动作卡片是独立参考；当前词汇没有完整的已确认动作映射时不会自动查词或拼接替代。仍非任意中文到中国手语生成或视频手语识别模型。

没有新增训练、修改原始动作或改变模型检查点。`training_ready`、`model_training_ready`、`csl_translation_verified`等仍为false，不承诺零抖动、零穿插或语言正确性。

## 独立运行方式

原生Swift/AppKit启动器通过包内CPython的 `-I -B` 隔离模式运行本机服务，移除外部Python/动态库路径环境变量。运行时由既有可重定位CPython与实际Torch/Transformers依赖闭包构成，不简单复制带有项目路径的虚拟环境。

模型服务只监听127.0.0.1，保留原Host、来源、请求体、会话、并发和公开资产校验。原生启动器验证状态文件的子进程PID、父PID、固定检查点和完整loopback URL后才打开浏览器。凭据不写入状态、日志或导航URL。

正常退出会终止并回收自己的子进程；强制结束启动器后，服务检测实际父进程变化并关闭。运行状态和非秘密日志存放在 `~/Library/Application Support/SignBridge Demo/`，不写应用资源。升级与卸载时可保留运行记录；卸载应用可使用Finder正常移至废纸篓。

## 验证与复现

复用经过逐文件校验的插件模型Demo包，执行：

```sh
/path/to/verified/python src/tools/sign-mac-demo-bundle.py \
  --delivery /absolute/verified/model-demo \
  --output /absolute/NEW/installer-build
```

构建脚本核验原包清单、复制模型/公开动作、收集23个已安装推理依赖及其源文件摘要、导出已有国际化词条、编译arm64启动器。依赖原始摘要记录在 `runtime-provenance.json`；之后的签名可能改变Mach-O文件，最终分发以签名后的完整应用摘要为准。

应用签名并验证后，用 `python src/tools/sign-mac-demo-bundle.py --output 构建目录 --installer 输出.pkg` 生成标准安装包。脚本固定安装至Applications并关闭应用路径重定位，避免安装器找到旧副本后写到演示构建目录。保留第三方运行时和包内许可文件。没有GitHub推送。

交付目录保留：隔离环境导入路径与动态库记录、真实模型与8段完整回放记录、正常退出/崩溃/重复打开/端口冲突记录、安装载荷比对和最终SHA-256。系统安装向导需要用户操作；自动验收使用从安装包提取的相同应用载荷运行，不冒充已执行管理员授权安装。


## 1.0.10 目录选择与安全校验

已复现1.0.8按钮提示路径正确、访达仍停留“手语”目录的故障。修复版本采用安装时自选插件目录、记住路径并直接打开的流程。

插件导出只包含BUILD.json列出的公开资产，逐文件核验SHA-256；拒绝来源、目标和BUILD.json符号链接与目录穿越。目录损坏时提示“更改插件位置”，不会要求反复重装到损坏目录。复制后核验通过才保存配置；原始视频、模型权重、Python运行时不进入插件目录。

验证含：空目录和自定义中文路径、取消选择、退出重启后路径保留、更换位置、非空个人目录拒绝、元数据符号链接拒绝、访达实际显示manifest.json、导出扩展的真实模型连接与播放。macOS最终安装仍由系统向导完成，不声称测试中执行过管理员授权安装。

本机实际测试中自动读取/唤起PKG发生系统调用阻塞，采样记录已保留。交付版不自动打开PKG；目录选择与保存异步执行，不阻塞界面，桌面安装采用上面明确的两步流程。
