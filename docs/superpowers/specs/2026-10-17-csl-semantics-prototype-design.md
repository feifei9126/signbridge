# 中国手语语义原型设计

用户已确认目标为中国手语，授权推进此前提出的“小范围语义分析 → 表达计划 → 有证据动作”原型。此次在同一会话执行，不启动训练或新代理。

目标是把中文句子的语义角色和动作检索分离；不把词库串联或固定词序宣称为正确的中国手语翻译。不使用字幕/句长来均分手势边界，不将观察视频等同于模型已学习。

## 范围

新增 Demo `semantic` 模式及一份可导出的分析对象。支持有限中文简单句：明确人物、时间、谓词、目标/受事、否定、能力/意愿/必要性、疑问。复杂结构和未支持词保留原文、报告原因，禁止输出省略关键意义的“完整翻译”。动作草案只复用现有词库的明确动作 ID，未批准视频候选不能成为可播放资产。

两种替代方案：继续增加整句别名难以验证组合泛化；直接训练文本到动作需要语义/边界/主体与测试划分的有效标注，目前不具备。此次选择可审计、有限规则的语义表示及严格覆盖闸门，明示它不是已训练的中国手语理解模型。

## 语义与表达草案

解析保留 actor、predicate、patient/goal、time、negation、modality、question 和源文本跨度。支持范围外的歧义、多句、被动/处置、条件、不完全词义均返回 pending。时间优先只是本原型的表达候选，不是“中国手语固定语序”结论。方向性动词、非手控疑问、空间指代都需要额外约束；缺少实现则阻止组合播放。完整已存在片段只能以 reference_retrieval 路由；不能称为语义生成。

## 教学视频证据

逐条读取既有80条教学词级参考索引，校验样本视频与关键帧摘要，输出新的候选语义索引和对照页，抽看“今天/昨天/明天”“来/去”的连续采样。所有词义/动作边界为 assistant proposal，human_approved/training_ready/model_training_ready=false。全句训练和静帧拟合不冒充词级连续轨迹。

## 验收

同义时间位置变换产生一致语义；角色交换、否定、能力/必要性、疑问保持不同。喜欢不能借用爱、没去不能变成去了、未知词/emoji不得丢失。缺动作/方向/表情约束阻止语义预览。完整参考原样保留；原有auto/dictionary/t08不改变。三种语言UI键完整。回归、构建、lint、格式和真实浏览器交互通过；保留显示修复资产和旧证据。
