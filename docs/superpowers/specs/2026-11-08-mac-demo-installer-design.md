# Mac 演示安装包设计

用户已要求把当前模型 Demo 制成一键安装包，沿用此前自主执行授权。目标平台为当前 Apple 芯片 Mac，不声称 Windows 或 Intel 兼容。

推荐本机独立应用：内置经过验证的 CPython、推理依赖、模型、动作和网页；原生启动器启动 loopback 服务，自动打开默认浏览器，退出时只终止自己的子进程。优于仅复制旧虚拟环境（存在项目绝对路径依赖）；云端托管需要服务器和新增运维，不纳入本次。

交付标准 macOS PKG，安装至 Applications；同时保留应用包和加载 Chrome 扩展的文件夹。插件无法静默安装，用户仍需在 Chrome 扩展管理加载；桌面演示无需插件即可打开。无可用开发者证书，采用本地 ad-hoc 应用签名，不冒充 Apple 公证，不更改 Gatekeeper。

运行时仅复制实际推理的依赖闭包，校验已安装版本与包文件。使用隔离模式运行内置 Python，拒绝外部 site-packages，离开项目目录并更换 HOME 后验证模型、HTTP 和完整动作回放。优先8787端口，若被占用只选择新空端口，不杀其他进程。模型保留原技术/语言批准边界，源参数与检查点不变。

验证包含：运行时路径和动态库审计、实际模型推理、完整人物播放、重复打开、端口冲突、正常退出和父进程消失清理、包内容提取与 SHA-256。只做本机交付，不推送 GitHub。
