# 原始骨骼候选库本地 Demo 实施记录

**目标：**按已授权四阶段，将 259 段完整候选在现有人物上筛选、预编译并接入本地展示包；实现有来源区分的有限中文角色表达和连续切换验收。

**架构：**复用 Godette、40 骨骼映射、固定平滑配置、腕部/手指质量指标及现有 Demo。独立原始候选契约保存源 NPZ/模型哈希，不冒用历史人工批准或 133D 训练特征。静态根部/下身/面部是显示策略，源参数保持原样。通过技术门槛的候选只允许明确的候选展示，原片词义仍未核准。

**边界：**1853 段封存不变；不训练、不修改 T08、不推送 GitHub。新几何风险另行隔离。不能把自动筛查、规则解析、平滑或离线预编译宣称为手语理解模型训练。
