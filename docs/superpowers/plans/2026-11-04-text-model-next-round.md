# 文字模型下一轮：冻结对照、错误归因与训练包

目标：执行已获用户授权的文字理解优化，先用新开发对照检验旧模型，再准备一次有明确变化的 GPU 研究实验。沿用既有小型 Transformer，不新增动作训练或修改 Demo。

范围：4,958 条中文—Gloss train、515 条 Gloss dev、6,355 条合成角色 train、881 条角色 dev；仅追加明确的合成中文角色监督。原始 Gloss 编号/顺序及文件字节保持，test 不读取。最新统一模型 epoch-013 作为诊断基线和新初始化，复用其已学角色头；原 epoch-040 初始化路径继续兼容，不声称恢复优化器。

选择：不重复增加旧数据训练轮数，不直接训练动作生成。新增开发对照同时测人物交换、词汇迁移、时间换序、否定/情态作用范围及范围外拒绝。对训练文本重叠单列；按实际训练BIO顺序核对结构留出，礼貌新词组合不算新角色顺序，不把所有对照都称独立测试。词级角色适配只覆盖能用现有 BIO 契约表示的中文语义；隐含谓词的“没有物品”等表示缺口不伪造标签。

- [x] 测试：新增工具的训练/评测隔离、原始 Gloss 字节保留、BIO/来源校验、新目录和哈希契约；统一模型批量推理加载一次且保持原 infer 行为。
- [x] 实现：`sign-csl-next-round.py` 生成并冻结对照、在新目录追加/划分合成角色样本，复用 `sign-semantic-contrast.py` 指标；`sign-csl-unified.py` 提供只读可复用推理器。
- [x] 实测：CPU 仅前向推理最新权重与旧感知机/作用范围实验，保存逐条预测、覆盖率、已接受正确率、错误接受、拒绝、配对和原始角色正确率。绝不在本机更新参数。
- [x] GPU：旧授权端口37077只读预检；拒绝连接则保存原始错误，完成本地训练包及输入/工具/初始权重摘要，不伪称已启动，不改用未授权机器。
- [x] 交付：新桌面“手语”目录保存报告、CSV、冻结样本、训练包与 SHA256；build/lint/格式/全量测试、本地提交，不推送。所有训练就绪/语义/词界批准继续 false，待人工审阅动作不动。

验收：primary 对照不与新角色 train/dev 重叠；新增 train/dev 组合不重叠；原始 held-out 内容未加入训练；新包通过现有 read_package。模型输入/权重在评测前后哈希一致。若远端不可用，本阶段可完成，GPU 参数更新明确记为未开始。

实施结果：90条冻结对照，当前统一模型正确目标13/74、误接受1/16；新增2,548条train和712条dev合成中文标签，角色总量8,903/1,593。epoch-013全部2,061,593个旧参数元素精确迁移，新输入字符醋增加128个参数。正式训练未启动：端口37077 Connection refused。GPU输入包23文件成员、独立评测及完整项目验证通过；专项PyTorch19项通过。详见 `docs/text-model-next-round-20261104.md`。
