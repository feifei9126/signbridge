# 32句字符Gloss记忆诊断

目标：执行用户已确认的下一步，先验证训练链路能否记忆32句，再决定是否值得做迁移学习。不是新泛化成绩，不接Demo。

固定：只打开既有train.jsonl（4368条）及其摘要/报告，不读取G/H/test；按seed20261106和ID的SHA256排序取32个唯一标准化中文句，排除train内部同文异标签冲突。词表由同一4368条train构建，沿用字符模型CONFIG。新随机初始化、AdamW学习率0.001、label smoothing0.05、batch32、最多1000步、每25步评估（含第0步）。这些是小样本链路诊断参数，不与全量训练性能作公平比较。

验收：自由生成至少31/32句原始Gloss完全匹配；32句均有合法词界/EOS；encoder/decoder/源与目标embedding/output各组梯度有限且非零、参数确实变化。teacher-forcing准确率单独报告，不用于替代自由生成验收。达到门槛即停止，不扩大为全量训练、不自动下载预训练模型。

- [x] 测试先失败：确定性抽样、train-only读取/摘要篡改、配置上限、teacher-forcing不替代自由生成、pad不计入token准确率、CUDA不可用不回退。
- [x] 实现独立prepare/train诊断工具，封存32句、词表、源样本摘要和计划。

- [x] 本机下载校验，复算32句并独立重现推理；build/lint/格式/测试、文档、本地提交，不推送。

实际结果：150步达到31/32、32句词界/EOS合法、五组梯度有限非零且参数变化。CPU逐条复现32句预测，已通过小样本记忆诊断；不称泛化成功，不执行迁移/全量训练。详见 `docs/tiny32-gloss-diagnostic-20261106.md`。
