# 基础语义纠错：冻结测试、错误归因与训练合同

入口为 `signbridge/src/tools/sign-csl-semantic-round.py`。本轮仅进行数据准备、旧模型的 CPU 推理与指标计算，
优化器更新为 0。没有启动 GPU，也没有改变旧权重、原始视频、动作、T08 或 Demo。

## 任务合同

模型需要分别表示：

- **entity**：裸人称，如“我”“我们”，不能凭空增加“是”等谓词。
- **event**：明确的单事件，以及施事、受事、目标、时间、体和有顺序的否定/情态操作符。
- **reject**：超出本轮受限合同或存在无法消除歧义的输入。合同外不等于不合语法。

“我不想去”和“我想不去”的操作符顺序不同；“我帮你”和“你帮我”的施事、受事不同；
“今天我去”和“我今天去”的同义对照保持相同角色及操作符。目标来自开发者构造的中文监督，
不能充当中国手语词序、Gloss 或动作证据。

## 本轮固定数据

共 345 条固定案例，包含单复数人称、单事件、情态/否定、宾语、目标、体、人物交换、时间语序和歧义拒绝。
有 61 对明确的同义或异义挑战案例。冻结文件在当前轮模型推理前写入，哈希保存在准备报告中。
本轮测试是工程开发基准，不是独立自然语言测试，更不是中国手语准确率测试。

首批训练合同包为 151 条 train、52 条 dev；138 条 challenge 全部保留作开发诊断，
其中已测过的案例不能在未来被称为未见最终测试。4 条与历史对照或 train/G 重合的训练候选已排除。
模板家族按 partition 分离；部分 BIO 角色顺序相同，报告会列出，不能据此宣称全部句法结构隔离。
旧角色训练文本的精确重合 ID 同时报告，评估还提供排除这些重合后的指标。

这是一份**小规模数据合同种子包**，并非充分的最终训练集。必须先补全专用训练器需要的实体分类、
拒绝目标与有序操作符输出，并为训练集合补足作用范围组合和拒绝样本覆盖，才能进入 GPU 实验。
不应将此包直接交给原 Gloss 多任务训练器；当前没有生成“现在可立即启动”的训练命令。

## 已验证的现状

沿用已核验的 4,368 train / 489 G 原始 Gloss 结果，按项目一致的最小编辑对齐计算全部模型错误。

| 模型 | 替换 | 删除 | 插入 | 人称表面不一致样本 | 否定表面不一致样本 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原基线 | 944 | 687 | 73 | 75 | 35 |
| 冻结续训 | 1,023 | 606 | 100 | 81 | 35 |
| 末两层适配 | 984 | 646 | 88 | 79 | 33 |

原基线错在训练中仅出现 1–2 次标签的次数为 242，错在训练未出现标签的次数为 245；
数字变体表面混淆 22 次。原始 train 中没有发现同一归一化中文对应多个不同完整 Gloss 序列的冲突。
这些只是错误和覆盖线索，不能证明源标签错误或近义变体等价；不会删除变体编号、修改原标签或去掉失败样本。

旧 averaged perceptron 与其“学习标签＋显式范围规则”版本保持分开评估。后者在本轮 138 条挑战上，
122 条合同内案例正确解析 118 条；16 条合同外案例错误接受 1 条；61 对对照通过 57 对。
排除旧角色训练文本精确重合后，合同内正确解析为 116/120，合同外错误接受仍为 1/16。
排除重合后只剩 59 对完整对照，通过 55 对；另 2 个单成员对不计入成对指标，仍保留在逐样本指标中。
52 条 dev 中正确解析 49 条，3 条裸复数人称全部拒绝。

这说明已有范围模块的有限中文能力比旧生成 Gloss 的结果更有针对性，但不能称为新训练成果，
也不能把显式规则的收益归给学习模型。已观察到的失败包括裸复数人称、4 条“不想来”组合和歧义“我没有工作”。
该诊断没有证明已经理解或能生成正确中国手语。

## 验证与恢复

准备工具只允许读取既有角色模型的 `model.json`、`weights.npz`、`train.jsonl`、`provenance.json` 与清单，
不读取旧 `test.jsonl`。原始 Gloss 结果经上一轮的完整哈希与逐条重算入口核验，H 和正式 test 本轮不读取。
新输出使用新目录；原始标签、全部历史失败和待人工动作审阅集合保持独立。

数据包校验覆盖身份、归一化文本、partition、角色 spans、BIO、操作符顺序、配对关系、来源及研究门槛；
数据包携带原冻结案例并用原始摘要绑定，每条训练/开发目标必须与冻结案例完全一致。
仅重算训练包清单无法掩盖同步修改 roles/spans/BIO 的标签篡改。拒绝/接受指标分开计算，
全部拒绝或全部接受不能拿到成功指标。排除历史重合时，成对指标只计完整双成员对照。

所有产物保持 `human_approved=false`、`semantics_approved=false`、`training_ready=false`、
`model_training_ready=false`、`can_play=false`。删除本轮新输出目录即可回退；无需恢复旧模型，因为没有修改它们。

```sh
python signbridge/src/tools/sign-csl-semantic-round.py \
  --delivery /absolute/verified/upper2-delivery \
  --role-model /absolute/existing/learned-roles-v3 \
  --legacy-fixture /absolute/project/signbridge/tests/fixtures/semantic-contrast-v1.json \
  --output /absolute/NEW/preparation
```
