## 采用结论与评估边界

不升级旧模型，不接入Demo，不继续使用H反复调参。G本来就是开发／选型数据，以上只是同组开发比较，不是独立泛化或中国手语准确率。控制token保留原始编号、变体及精确词界，不存在合并标签刷分；训练过程也未使用旧checkpoint或新增合成Gloss标签。

字符表示的技术链路已经跑通，但当前小模型、数据量及监督形式未因此解决词汇选择、短输出和否定范围问题。后续若研究更强的文本表示或标签共享，须另立冻结实验与新评测边界，不能继续把H称作未使用留出。当前 `human_approved/training_ready/model_training_ready/deployment_ready` 继续false。
