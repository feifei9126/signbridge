# 基础格式扩展数据库（2026-11-09）

本轮沿用127项基础库的分类、来源绑定和动作验收门槛，整理其余现有资料。新增目录保存SQLite、JSONL、来源快照、独立检查记录和离线检索页；原视频、原参照库、原动作参数、旧修正版本和模型权重不覆盖。

Gloss索引、文字词条、原句和汉字的计数不能直接相加当成不同动作数。相同字形只合并精确类型一致的检索项，各来源释义、手型说明、非手部说明和不确定性分别保留；不据此断言动作同义、镜像或解剖学手别相同。

全库继续保留6,315个来源样本，包括44条未标注完整课程和28段基础候选。573条教学细标、255条课程候选及127条基础说明构成955条来源证据。21条章节/理论标签仍保留为排除证据，不进入词库。

## 修正的具体问题

- “你家在哪里”的同一候选片段已在基础库判为完整问句，却在旧候选分类里标为word_candidate。以同一caption ID、精确文本和唯一基础类别为依据，合并到句子检索项，保留原分类和转换记录。不是根据字数判断，也没有修改源视频或批准动作。初版750项中因此减少一个重复的词项，最终749项。
- Gloss索引明确分为全部来源引用、保留样本引用和隔离样本引用；隔离行仍能溯源，却不进入用于展示的保留样本例句。
- 排除的21条标签也保留原始及有效分类，避免“未入词库”变成“记录丢失”。
- 动作通过数只统计当前来源/动作/标注版本真正通过的两轮，不把版本不匹配或只写了passed的旧记录算入。

## 实际验证

构建时重新核对冻结清单与元数据，重新打开283条动作映射，实际重读24,832帧原生参数的形状、dtype与有限值，并验证原生参数/metadata/render帧集版本。225条映射原生帧集完整，32条部分缺失，26条无原生映射；这些是技术完整性结果，不能替代手型、掌向、动作路径、表情和碰撞正确性。

另有独立程序回读CE-CSL原始train/dev/test CSV全部5,988行，对照原句、Gloss、源行哈希和来源split；检查全部教学细标、候选、基础条目与扩展表，交叉核对SQLite和JSONL。独立媒体程序对冻结清单中的6,362个唯一媒体重新哈希并实际完整解码，记录退出码、stderr、帧数、尺寸和fps。最终检查结果以交付包validation目录中的实际报告为准，不能把运行中的进度写成完成。

初次独立来源审计指出6个Gloss引用列表和21个排除项字段不完整；失败报告留存，修复后在新版本重跑。构建与JavaScript测试曾并行争用dist目录，导致一次BUILD.json缺失；已改为先完成构建再运行测试，失败日志与最终日志分开保留，不修改程序掩盖检查失败。

## 两次完整验证门槛

仅当同一个source SHA、clip SHA、action version SHA和annotation SHA上，两个不同方法的完整动作复核都通过以下9维，才能将动作标为通过：词义、手型、掌向、位置、路径、非手部表达、边界、时间稳定、碰撞。任一unknown、缺失或版本修改都会阻止通过。

媒体解码、来源CSV一致、数据库结构正常与两次完整动作通过是不同层次。当前扩展库不发布新的动作批准，不启动网络训练，不替换Demo或T08，也不推送GitHub。此前仅对展示的“你”关键帧给出的用户认可不会扩大到其他词或完整片段。

新库只整理现有材料；CE原句仍无词级时间对齐，不将整句视频机械切成每个Gloss对应的动作。手语人物、镜像、手别和项目split继续保留未确认状态，CE原始来源split保持原样。测试集被回读用于完整性审计，不用于本轮训练或选模型。
