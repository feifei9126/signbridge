# CE-CSL dev 错误分析（2026-10-23）

## 范围与结论

比较首轮 epoch 40 与 GPU 权重初始化续训选中的 epoch 11 保存的 dev 预测。两轮各 515 条，6 条与 train 重叠，主要比较切片为剩余 509 条。工具不调用训练/推理、不载入模型，不打开 test 样本或 test 预测；仅对选中检查点做字节摘要核验。所有模型、标签、词界和动作批准状态保持原样。

主要结论：目前首先需要改进中文到 Gloss 的词汇选择及上下文建模，而不是盲目增加轮数、合并编号标签、机械换词序或强制去重。这是由 dev 观察得到的后续实验假设，不是已经证实的因果解释，也不是新的独立测试成绩。

## 两轮比较

| 非重叠 dev 指标          |              首轮 |          GPU 续训 |
| ------------------------ | ----------------: | ----------------: |
| 参考条数 / Gloss 数      |       509 / 2,307 |       509 / 2,307 |
| Gloss 错误率（越低越好） |            71.30% |            71.39% |
| 替换 / 删除 / 插入       | 1,058 / 447 / 140 | 1,052 / 429 / 166 |
| 整句完全匹配             |                 6 |                 7 |
| 预测比参考短 / 长的句数  |          263 / 79 |          250 / 99 |
| 纯同词异序线索句数       |                 5 |                 5 |
| 相邻重复过量计数         |                13 |                17 |
| 编号表面相同的替换线索   |                14 |                20 |

续训使 84 条编辑错误数下降、101 条上升、324 条持平。总计少 6 次替换、少 18 次删除、多 26 次插入，因此总错误多 2 次。上述编辑对齐有并列最短路径；词级归因使用固定规则，仅供诊断。

### 不是只有生僻词或编号问题

train 有 4,973 条、23,293 次 Gloss 出现、3,838 种标签，其中 1,893 种只出现一次（约 49.3%），2,517 种只出现一两次。标签稀疏确实存在，但续训的 1,481 次参考词替换/删除中，只有 204 次涉及 train 频次 1–2 的标签、14 次涉及未见标签；其余 1,263 次（约 85.3%）涉及 train 频次大于 2 的标签。这个阈值是描述性分组，不是训练超参数。

常见词同样不稳定。例如按照固定编辑对齐，续训多插入“我”19次、漏掉“我”15次；“我”在 train 中出现 1,313 次。“这里”出现 163 次，仍被删除 10 次并被替换成“这”6次。不能把这些错误全归因于未知词。

### 数字、重复与语序

- 16 条包含纯数字标签的 dev 句子，整句 Gloss 错误率从 83.52% 降至 67.03%，但两轮各有 25 次数字参考标签替换/删除；切片整体变好不等于数字理解变好。
- “我们喝茶还是喝咖啡？”一例出现连续重复“茶”，是具体的解码退化线索。但参考中合法重复也可能存在，不能全局去重。
- 只有 5 条续训结果属于相同标签多重集合、顺序不同，其他错误通常还含错词或漏词，不能靠统一换词序修复。
- 编号表面相同仅用于观察，例如 `考试1` 与 `考试2` 仍作为不同原始标签计分，不合并来提高成绩。

## 下一轮受控实验方案（尚未执行）

1. **先冻结对照条件。** 保持原始 train/dev 划分、原始 Gloss 标签和 train-only 词表；以首轮权重为保留基线。test 已在首轮使用过，不再当成新独立评估。除整体 dev 外同时报告删除/插入、否定线索及常见/稀有标签切片，不能只展示改善的局部。
2. **低成本先检验解码假设。** 固定首轮权重，预先确定少量 beam/长度归一化候选，检查重复输出、插入及遗漏的变化。只运行推理，不以参考答案逐句纠正输出。拒绝任何“全部去重”或强行按中文词序拼装标签的捷径；即使 dev 改善也不能宣称独立泛化。
3. **再决定是否训练结构改进。** 若词汇替换仍占主导，可研究保留原始编号输出的标签字符/子词共享或源文本对齐辅助；先比较数据与代码复杂度，不立即扩大模型。任何参数更新仅在已授权 GPU 上、使用新来源绑定目录执行。
4. **晋升门槛。** 不允许主要 dev 非重叠错误率变差后仅凭训练 loss 或一两条整句正确就替换基线。新方案必须同时审查插入、删除及否定相关退化；没有新独立评估，不开放自动手语表达或接入 Demo。

## 复现与证据

新增工具 `signbridge/src/tools/sign-ce-csl-gloss-errors.py` 只使用标准库，并复用既有原始标签指标契约。入口以哈希绑定的文件与稳定 ID 比较；标签、样本、词表、来源或保存指标不符即失败，且必须使用不存在的新输出目录。

从仓库根运行：

```sh
python3 signbridge/tests/sign-ce-csl-gloss-errors.test.py -v
python3 signbridge/src/tools/sign-ce-csl-gloss-errors.py \
  --library local-data/ce-csl-intake-20261022-v1/candidate-library-v1 \
  --prior local-data/ce-csl-gloss-training-20261022-v1/experiment-v1 \
  --continuation local-data/ce-csl-gloss-gpu-20261023-v1/download-verified-v1/extracted-clean-v2/ce-csl-gloss-gpu-20261023-v1/results/continuation-v1 \
  --output local-data/ce-csl-dev-errors-new
```

本次最终快照位于 `local-data/ce-csl-dev-error-analysis-20261023-v3/`，先前 v1/v2 保留：

- `report.json` / `REPORT.md`：切片统计。
- `cases.csv` / `cases.jsonl`：全部 515 条逐句对比与固定编辑路径；CSV 防止公式注入。
- `top-confusions.json`：非重叠切片高频误判、train 标签频次。
- `source-provenance.json` / `SHA256SUMS`：输入、选中检查点、分析代码和输出摘要。

真实数据运行另加文件访问拦截，test 文件访问尝试为 0。代码审查发现父目录符号链接可能在摘要检查前引向 test；已补充先失败后通过的回归，所有输入读取及检查点哈希在打开文件前逐级拒绝目录/文件链接，最终来源复核同样检查。v3 用修复后的工具重新生成，未修改原训练证据；它适用于不被其他进程并发恶意替换的本地快照，不宣称抵御文件系统竞态攻击。

切片存在重叠，不可相加。重复、否定、数字、稀有标签和语序分类均为自动诊断线索，不是中国手语语义、词界或人体动作审核。`training_ready`、`model_training_ready` 和 `deployment_ready` 均保持 false，数据和权重不自动公开上传。
