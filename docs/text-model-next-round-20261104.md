## 90条冻结开发对照

74条目标句、16条范围外或歧义输入，文本均不与当前四个train/dev集合重合。覆盖人物交换、词汇迁移、时间换序、事件状态和作用范围。额外逐项核对训练BIO顺序后，32条目标句具有训练中未出现的角色顺序：16条复合作用范围、8条否定能力、8条无宾语事件状态。原冻结清单把2条礼貌新词组合也归在structural_holdout，该名称不代表新结构：礼貌角色顺序已出现在旧训练中，单独降为词汇组合对照。核查记录在 `validation/structure-holdout-audit.json`。这些是助手编写的中文工程契约，不是人工语义批准或中国手语准确率；旧初始化的历史重叠限制继续保留。

## 具体缺口与口径修正

- 新核心词跑步、洗澡、开车缺少旧角色训练支持；汉字出现于Gloss语料不等于模型学会其角色边界。
- 旧统一模型在复合否定/情态上仍拒绝。原始角色标签正确与最终解析接受分开计数，不能把结构拒绝全部归因于权重。
- 三种策略均误接受“我没有工作”：它可能表示无职业或事件否定。新数据不为歧义强行制造唯一答案，仍保留为研究缺口。
- “回家”和“回＋家”只按这一条明确等价规则视为同义事件，另报严格角色匹配。baseline-v1未作等价处理，不能把计分修正称为模型提升。
- preparation-v1新增分组未继承旧组合，已保留为检查修正前证据，禁止训练。preparation-v2继承旧分组；组合及90条评测文本均不跨训练/验证。

最终基线为 `baseline-v3/report.json` 与 `cases.csv`。v1/v2原样保留；v3使用最终代码，但冻结句子和目标含义没有根据预测修改。
