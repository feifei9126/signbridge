# 基础词组精标与动作复核

本轮按用户要求，先在既有新参照数据库上建立常用基础库，再将字、词、词组、句子、来源Gloss和动作证据分别记录。用户追加硬条件：同一版本动作对照视频两轮独立全项验收通过才允许训练；修改后两轮重新核验，证据不足不算通过。本轮没有训练、没有改T08或Demo、没有推送GitHub。

## 基础库

选择127个有明确使用场景的基础目标：最终96词、17词组、14句子，含人称、时间、地点、问候、常用动作/否定、亲属称谓、基本问答。71项能找到实际来源参考片段；56项只有原课或整句证据，尚没有可独立核验的片段。它们仍保留缺项，不能复制同字形的别词动作。

中文释义来自已有课程审计或明确的一般中文语义，不能据此称中国手语手型已国标认证。问候表达的构成与话语功能分列，例如“你好/早上好”作为固定表达也能独立使用；不因能独立使用就自动认定词级动作起止。

- 573条原教程义项全部有本轮细化记录，原类别和来源SHA保留：453词、27词组、26句子、35指拼、9数字、8语法、10手语名、5类标记。不同分类口径的提案保留，不回写旧审计。
- 255条附加字幕候选全部分类；主助手直接查看15张板中89份实际原片中间画面，修订栏目混入、错字和漏字。原OCR保留。21条章节/理论内容不进入普通词库。
- 明确修订包括“延量→邮局”“词汇拓展重→举重”“你家有几日人→你家有几口人”“服务好，莱好吃→服务好，菜好吃”。“词汇拓展”独立栏目不当作词；“要净手”画面实为讲解饰物手链，隔离为上下文，不创造“净手”动作。
- 2087个去重汉字组件仅是来自原句/标签的书写字符，可能保留尚未纠正的OCR字形。单字可同时作为词，但每个字不自动有独立手势；不把学校的学、校强行切动作。
- 6315个源样本/参考记录全部保留覆盖状态：CE为整段Gloss标注无词级帧界、无标注整课为reference，实际片段另有技术观测。dev/test不混进训练，也不参与优先词训练频次（这里只读取原train来源频次）。

## 动作技术检查

283段实际来源片段、29438帧全部解码并保留无平滑MediaPipe身体/手部/468点脸部观测。28段旧观测哈希与源PTS/帧ID验证后复用；其余255段重提取。漏检保留NaN和精确mask，不补零、不插值。早期进程中断时68项已有完整报告，恢复版本只在验证输入/输出哈希后复用，未重复处理完成片段，旧证据保留。

额外255段候选已按candidateID、sourceSHA、clipSHA关联历史原生骨骼；本次重读完整参数/metadata/render文件，核对固定alias/sequences索引和实际运行报告，不能把映射中任意目录换作该候选。223段参数完整，32段缺帧隔离。基础“我/你”的原生输出按67/60帧源映射另验后加入，最终257段：225完整、32不完整；其余26基础片段缺少精确整段原生映射。

空间检查将保存的原生SMPL-X关节和手指顶点（含原手部mean）投影，与未平滑的原片观测比较；另一组检查比较运动方向、腕部速度、有效旋转变化。手别未完成解剖/镜像校准，使用同名slot不自动交换降低误差。高像素误差、漏检、瞬间大角度只能提示需要纠正/更多证据，不等于原视频动作错误。2D前臂交叉不能证明3D穿模，必要接触不能自动拉开。

## 双轮门禁

当前完整动作双轮全项通过为0，训练允许为false。空间与时序两类检查已经运行，但它们不覆盖三维手型/掌向/深度、词义与表情、精准词界、全动作碰撞等所有维度，**不得把它们写成两次完全一致验收**。

门禁绑定sourceSHA、clipSHA、动作版本SHA和annotationSHA；动作版本包括本次实际读取的原生参数、metadata、render精确集合。标注版本覆盖真实原教程义项、细化释义/不确定性、基础定义及片段的源PTS/帧ID/实际边界。任何修改均须重做两轮。两轮必须编号1/2、方法不同、同版本、全源帧范围，语义、手型、掌向、位置、路径、非手部、词界、稳定性和碰撞均有passed；unknown与只有关键帧不放行。

用户对当前展示“你”的认可继续保留在原review及具体校准关键帧，不冒充全连续动作双pass。原生未修复基线与校准关键帧分别展示，不由用户认可一张对照图就改所有“你”样本审批。

## 文件与验证

本轮研究根：`local-data/csl-foundation-refinement-20261109-n9ujus4p/`。最终交付为桌面“手语”的版本化基础库，含原片、完整继承的视频索引、原生动作副本/逐帧清单、原片/旧骨骼对照视频、CSV、SQLite、字符组件、分类与双轮门禁缺项记录。旧参照数据库和失败/被替代输出不覆盖。

工具：`sign-csl-foundation.py`负责分层基础库和门禁；`sign-csl-foundation-observe.py`负责原始观测；`sign-csl-foundation-compare.py`负责原生与原片技术对照；`sign-csl-foundation-review.py`负责离线检索播放。相关回归在`signbridge/tests/sign-csl-foundation.test.py`。版本绑定审查发现的三个重要缺口均分别加入测试：释义变更影响标注摘要、任意换原生目录被拒绝、参数变化使当前动作摘要失败。

本阶段产物不构成“全部动作已正确”或“模型已经理解中国手语”的声明，训练继续被门禁阻止。剩余问题应按逐动作记录修正后重新验收，不能以增训练轮数掩盖错误目标。
