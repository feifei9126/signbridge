## 当前训练的任务

输入中文，输出施事、谓词、受事、目标、时间、否定、情态、疑问、体貌、请求和程度的角色跨度。实现为 NumPy 平均结构感知机，学习字符上下文特征和 BIO 转移权重；不是整句查表，也不是神经大模型。范围检查取自训练集，不给未知结构或对象关系猜答案。不提供伪装成概率的置信度。

训练与验证标签全部为 `assistant_synthetic_chinese`，没有用未经核验的视频标签更新权重。数据按“施事／谓词／对象”组合分组留出，同组变体归同一集合，三个集合文本不重叠。挑战集另写并排除出全部生成样本。它们均属于受限、同一开发者构造的测试；高分不能推导为真实中文或中国手语准确率。拒绝只意味着超出训练证据范围，不是对一切可能语境的语言判断。

本次运行保存在 `local-data/csl-understanding-20261017-rLaeiN/learned-roles-v3/`，包含 JSONL 数据、无 pickle 的 NPZ 权重、模型元数据、完整评估错误、工具／输入哈希和 SHA256SUMS。根目录最初实验独立保留，收紧合成标签并加入参数支持范围的 v3 才是当前模型。旧 T08–T10 及六批原始数据没有改动。前两次实验原样保留；v3 收紧了请求句、形容词情态和谓词对象搭配，避免把明显不自然的自动组合当作正例。

从扩展目录重新训练，输出必须为新目录：

```sh
../.venv-sign-data/bin/python src/tools/sign-csl-learned.py \
  --output ../local-data/csl-roles-new-attempt --examples 8000 --epochs 14 --seed 17
```

## 私有客户端

`npm run build:private` 只构建单独的 `dist-private/`；已有输出目录会拒绝覆盖。也可用 `SIGNBRIDGE_PRIVATE_BUILD_DIR` 指向一个尚不存在、父目录已存在的新目录。构建有严格文件清单和逐文件哈希，不复制原 Demo、词库、权重、动作、视频、编辑器或研究语料。`.gitignore` 排除该输出。

可检查客户端在本地交付目录的 `private-client-v2/`，ZIP 仅含其六个文件。Chrome 开发者模式可加载这个目录，点击扩展图标打开私有页面。它不是原完整版插件的自动更新，不会替换旧插件。也可直接使用同一服务的本地网页。

从扩展目录启动服务：

```sh
../.venv-sign-data/bin/python src/tools/sign-private-serve.py \
  --model ../local-data/csl-understanding-20261017-rLaeiN/learned-roles-v3 \
  --client ../local-data/existing-resources-optimization-20261019-v1/thin-client-v1.0.5 \
  --port 8770 --scope-experiment \
  --unit-candidates ../local-data/existing-resources-optimization-20261019-v1/unit-candidates-final/candidates.json
```

打开终端显示的 `/private/index.html` 页面，填入终端本次生成的会话口令即可。口令不写入文件、URL、报告、浏览器存储或安装包，重启服务即失效。清空／退出页面会清除页面内存口令。插件跨来源连接还需启动参数 `--allow-extension chrome-extension://准确的32位扩展ID`；普通网页无需此参数。不得填通配符。

从普通本机网页打开分析页时，客户端会先检查服务是否监听；未启动会留在当前页并显示上述命令，不再跳入浏览器连接错误页。健康检查不发送口令或分析文本。

接口只有 `POST /v1/understand`，输入为 `{"text":"我帮你"}`。返回当前句子的语义角色和模型版本；不会返回完整词表、训练集、权重或动作库。解析成功仍返回 `csl_translation_trained:false` 和 `requires_csl_alignment_review`，没有词库播放回退。输入最多500字／8192字节，单进程所有连接共享60次／分钟，最多12个连接和2次并发推理。只绑定127.0.0.1，校验 Host、准确 Origin、随机 Bearer；只允许三个静态客户端文件，禁止目录浏览，响应不缓存，访问日志不记录原文或口令。

可选候选证据文件只接受普通 JSON 文件（最大5 MB、最多1000项）；ID 限128字符且唯一，候选文本限80字符，同一文本最多8项。任何标为已人工批准、边界已验证或可训练的行都会被拒绝。服务仅向客户端返回短 ID 与精确文本匹配结果，不返回原始路径、视频摘要或其他训练/动作资产；输出仍固定为 `human_approved:false`、`word_boundaries_verified:false`、`training_ready:false`，且不可播放。客户端也会拒绝超长 ID 和任何可播放计划。

此服务用于可信本机开发，尚非互联网多用户服务。上线仍需独立 HTTPS、账户与授权生命周期、配额和撤销方案；不能直接暴露公网。客户端收到的语义结果或渲染画面仍可能被复制或录制，无法承诺绝对防提取。未来保护原始动作应优先在服务端渲染，而不是发送完整3D关节数组。

## 六批视频的下一阶段

`src/tools/sign-csl-data-readiness.py` 读取既有审计、验证教学资产哈希，并生成新对齐队列；不重新审核或撤销已有批准，不把字幕自动当词级 Gloss。

本轮生成304条候选复核记录：200个连续原生任务、24个二维参考、80个教学词／步骤候选；这些是阶段记录，不能当304个唯一正确句子。720个教学资产哈希通过，五个重点片段完整解码通过。只查看了五张关键帧联系表，未逐帧看完所有视频或确认手语正确。缺失帧和失败继续保留并排除，镜像、侧别、手语者、数据分组和词级边界不凭空填写。原视频来源 SHA 仅引用，未重新哈希原视频。

下一模型需要“中文语义 ↔ 已核验手语词／短语时间区间 ↔ 身体、双手及非手部表达”，并按来源和手语者留出评价。当前未建立可直接使用的已核验词级 CSL 训练对，故 `human_approved/training_ready/model_training_ready` 继续为 false。中文角色模型是第一项可运行实验，没有补齐手语语言标注。
